# Brief – EF Agency
Dato: 2026-11-07. Ejer har instrueret at bygge uden interview eller ekstra godkendelse. Designbeslutninger er udviklerens arbejdsvalg, ikke særskilt godkendte fakta.

Virksomhed: EF Agency, nystartet af Emil Dannemand og Frederik Bech. Målgruppe: virksomheder. Kortvideoer, videoredigering, undertekster/hooks/musik/animation og contentplan/filmning. Kontakt: efagency99@gmail.com. Primær handling: start en samtale via mail.

Ydelser og pakker: Edit Starter (4 videoer, op til 30 sekunder), Edit Plus (8 videoer, avanceret klipning), Content Partner (12 videoer, idéer/plan og filmdag op til 3 timer). Alle med én korrekturrunde. Kilde: Shopify-siden læst 2026-11-07. Kildepriser 995/2.229/4.499 kr. pr. måned, momsstatus MANGLER; derfor vises antal og omfang, mens tilbud aftales direkte. Ingen opfundne bindende vilkår eller leveringstider.

Struktur: onepager med ydelser, koncepter/cases, proces, pakker, om os, FAQ og kontakt. Separate juridiske informationssider. Ingen kundeprojekter opfundet.

Brand: designforslag fra udvikleren, nyt filmisk/redaktionelt univers. Den tidligere papir/rød-retning er afvist. Ny retning med charcoal-sort, varm hvid, gul og koboltblå fotomotiver, inspireret af Clix Productions og Umault. Selvhostede Manrope og Barlow Condensed. Logoets identitet bevares efter ejerens sidste sætning og leveres i SVG. Store overskrifter, billedbårne konceptdemonstrationer, åbne lister frem for gentagne kort.

Skills: website-byggemanual bruges gennem hele forløbet. Impeccable installeret lokalt og bruges fra start, audit/critique/polish til slut. Lenis, GSAP/ScrollTrigger, React Bits og Magic UI med adskilte roller. Fuld bevægelse på desktop, forenklet på mobil, statisk ved reduced motion. Officielle komponentregistre anvendes uden global MCP-konfigurationsændring.

MANGLER før lancering: registreret navn, CVR, adresse, telefon hvis ønsket, momsafklaring, domæne, kundeprojekter, portrætter og billedgodkendelser, præcise aftalevilkår, databehandleraftaler, rigtig afsendertjeneste hvis serverformular ønskes. Geografisk område er ikke opfundet. Ingen analytics/pixels eller marketingcookies installeret. Ikke publiceret.
